How every heat works

Playable events are 8-athlete heats in full MuJoCo physics. The Long Jump Scramble remains a 16-athlete event concept and is not playable yet.

  • Roster: playable heats use eight lanes; the menu assigns roster athletes to those lanes.
  • Crowd contact: all athletes collide under MuJoCo physics. The tightest layouts include the Iron Pedestal, Gust Gauntlet, 30m All Fours, Crab Shuffle, mirror Slalom, Turntable and Terminal Velocity Sprint.
  • Long Jump Scramble: planned as 16 athletes running and jumping in overlapping waves toward a shared sandpit; it needs a 16-athlete event scene before it can be played.
  • Brains: Rung 0 = stand and recover from shoves; Rung 2 = walk and run in any direction plus turning (up to ~3.8 m/s). Future rungs add stance skills, get-up, terrain, jumps and special skills.
  • Where to play: Unity scene MainMenu (pick 8 athletes and an event), or the Stadium_Hub flyover.
